# Workday Tracker — версия для публикации и iPhone

В папке лежат статические файлы PWA: `index.html`, `manifest.webmanifest`, `sw.js` и иконки.

## Публикация без компьютера (с iPhone)
1. Откройте Safari и зайдите на https://app.netlify.com/drop .
2. Если сервис предложит войти/зарегистрироваться — выполните вход.
3. Важно: Netlify Drop обычно удобнее загружать папкой сайта. На iPhone это может зависеть от версии iOS и интерфейса сервиса. Если папку выбрать нельзя, используйте загрузку через компьютер или GitHub Pages.
4. После публикации сервис покажет HTTPS-ссылку сайта.
5. Откройте эту ссылку в Safari на iPhone → кнопка «Поделиться» → «На экран Домой» → «Добавить».

## Данные
Смены и настройки сохраняются в локальном хранилище браузера на устройстве. Не очищайте данные Safari, если не сделали JSON-резервную копию. Установка на главный экран сама по себе не синхронизирует данные с другими устройствами.

## Ограничения
Это PWA-веб-приложение, не нативная сборка App Store. Для расчёта налогов, сверхурочных и правил трудового договора нужна отдельная настройка.
